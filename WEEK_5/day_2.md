## Mini Project
### 🩺 AI Medico Bot

Developed an AI-powered assistant capable of analyzing medical report PDFs, generating summaries, explaining medical terms, and answering user queries using Retrieval-Augmented Generation (RAG).

### Technologies Used
- Python
- Streamlit
- LangChain
- Google Gemini
- Ollama
- FAISS

### Learning Outcome
- Built a document-based AI assistant.
- Explored both cloud and local LLMs.
- Improved understanding of RAG workflows for real-world applications.
