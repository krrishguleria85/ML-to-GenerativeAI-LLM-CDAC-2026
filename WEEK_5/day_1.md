## Mini Project
### 📄 Mini RAG Chatbot

Built a simple RAG chatbot that allows users to upload PDF documents and ask questions based on the document content.

### Technologies Used
- Python
- Streamlit
- LangChain
- Google Gemini
- HuggingFace Embeddings
- FAISS

### Learning Outcome
- Understood the complete RAG pipeline.
- Learned how vector databases improve information retrieval.
- Integrated Gemini with LangChain for document-based question answering.
